# EmotiVoice

> 网易有道出品的开源中英双语情感语音合成引擎，提供 2000+ 预置音色。

## 基本信息

| 项目 | 详情 |
|---|---|
| 开发者 | 网易有道 (NetEase Youdao) |
| 语言 | 中文、英文 |
| 预置音色 | 2000+ |
| 许可证 | 开源 |
| 仓库 | [github.com/netease-youdao/emotivoice](https://github.com/netease-youdao/emotivoice) |

## 核心能力

- **中英双语**：同时支持中文和英文语音合成
- **2000+ 音色**：内置超过 2000 种不同的预置音色
- **提示词控制**：通过演绎提示（开心、悲伤、愤怒等）控制语音情感，也可输入自己的简短描述

## 在本项目中的适配

- 本地运行
- 使用官方开源预训练说话人 ID 和情绪提示词
- 当前本地推理会自动处理中英文混读，不需要单独切换语言
- 这是官方预置音色路线：不能上传一段参考音频立即复刻。官方的“个人音色克隆”是另外一条训练流程，本项目当前没有把那条训练流程接入生成页
- 采样率：16000 Hz
- 适合短句和音色预设试听场景

## 适用场景

- 中文角色配音和情绪短句
- 音色预设试听和筛选
- 教育和交互式语音应用

## 当前参数与默认值

EmotiVoice 当前使用官方开源预训练 speaker 和中文情绪提示，不使用本地音色库的 `voice_id`。生成页会从本地 EmotiVoice 仓库读取官方 speaker catalog；如果仓库未配置，会回退到项目内置精选 speaker，避免页面空转或卡死。

| 参数 | 默认值 | 大白话说明 |
|---|---:|---|
| 说话人 `speaker_id` | `8051` | 官方预置音色 ID。不是本地上传音色。 |
| 演绎提示 `prompt` | `开心` | 决定这句话怎么演：可点选 8 个常用情绪，也可直接写“克制、略带疲惫”等简短描述。开心通常更亮、更有活力；悲伤更收敛。先用短句试听。 |

内置预设：清晰女声开心、浑厚男声中立、活泼女声兴奋。生成页“一键重置参数”会恢复到默认 speaker 和提示词。
