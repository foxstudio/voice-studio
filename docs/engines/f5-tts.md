# F5-TTS

> SWivid 团队基于 Flow Matching + DiT 的非自回归零样本语音合成模型。

## 基本信息

| 项目 | 详情 |
|---|---|
| 开发者 | SWivid |
| 架构 | Flow Matching + Diffusion Transformer (DiT)，非自回归 |
| 最新版本 | v1 Base (2025 年 3 月) |
| 许可证 | 开源 |
| 仓库 | [github.com/swivid/f5-tts](https://github.com/swivid/f5-tts) |
| 论文 | [OpenReview](https://openreview.net/forum?id=JiX2DuTkeU) |

## 核心能力

- **零样本声音克隆**：仅需 5 秒参考音频即可克隆音色
- **非自回归架构**：基于 Flow Matching 的 DiT，推理效率高
- **长文本支持**：支持整本书/长脚本的连续语音生成
- **可微调新语言**：支持针对新语种进行微调训练
- **高质量自然度**：被社区认为是最逼真的开源零样本 TTS 之一

## 在本项目中的适配

- 本地运行
- 采样率：24000 Hz
- 提供高级参数：NFE 采样步数、CFG 引导强度、RMS 响度、交叉淡化、静音移除
- 支持语言：中文、英文

## 适用场景

- 已授权参考音色的跨文本复刻研究
- 长篇有声读物和脚本生成
- 音色迁移实验

## 当前参数与默认值

F5-TTS 在本项目中走本地参考音频复刻。生成前需要先在音色库选择带参考音频和准确参考台词的音色；项目不会自动听写参考音频来补 `ref_text`。

| 参数 | 默认值 | 大白话说明 |
|---|---:|---|
| 语速 `speed` | `1.0` | 控制目标文本朗读速度。 |
| 采样步数 `nfe_step` | `32` | 越高越细，但越慢；快速试听可以降到 16。 |
| 引导强度 `cfg_strength` | `2.0` | 控制目标文本和参考音色的约束强度。 |
| 响度目标 `target_rms` | `0.1` | 控制输出音量目标。 |
| 分段交叉淡化 | `0.15s` | 多段拼接时减少衔接突兀。 |
| 采样摆动 `sway_sampling_coef` | `-1.0` | 开发者参数，影响采样时间步形状；普通用户保持默认。 |
| 固定总时长 `fix_duration` | `0` | 开发者参数，0 表示自动估算；填写秒数会尝试固定参考音频与生成音频总时长。 |
| 移除静音 | `false` | 短素材剪辑可开启，长旁白建议谨慎。 |

内置预设：官方默认复刻、快速试听、短句去静音。生成页“一键重置参数”会恢复以上默认值。
