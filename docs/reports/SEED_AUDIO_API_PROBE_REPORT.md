## 3. 当时采用的安全与成本门禁

- 默认 dry-run 不加载现有秘密存储中的 Key。
- 只有显式执行真实验证时才通过项目秘密存储读取 Key，且不打印、不落盘。
- 单次 CLI 运行最多发送 1 个请求，不自动重试。
- 单次请求按 120 秒上限估算最大成本为 2 元；完成后按 `original_duration` 记录估算费用。
- 输出只保留脱敏请求摘要、HTTP 状态、请求 ID、`X-Tt-Logid`、原始时长和成本。
- Base64、speaker ID、临时 URL、Key 和可能包含它们的错误信息必须脱敏。
- 每次运行使用隔离临时目录，退出时删除运行目录；不删除调用方的工作根目录。
