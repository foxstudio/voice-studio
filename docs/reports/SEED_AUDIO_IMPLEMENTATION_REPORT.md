# Seed Audio 1.0 实施与验收报告

- 日期：2026-07-11
- 当前结论：本地功能与文字、参考语音、参考图片三模式真实云端验收完成
- 入口：现有 `/generate` 语音合成页面
- 引擎 ID：`doubao-seed-audio-1.0`

## 用户现在能看到什么

- 在现有引擎列表中选择“豆包音频生成 Seed Audio 1.0”。
- 选中后，顶部沿用现有参数行，依次显示引擎、模式、语速、格式、重置和高级选项。
- 模式为文本、语音、图片三项，默认文本；格式和采样率始终可见。
- 语音和图片模式无法默认的必填素材直接显示，不会藏进高级设置。
- 参考声音模式提供 3 个固定槽位；每个槽位支持音色库、豆包云端 speaker、自定义音频上传、试听、编辑、裁剪、替换和删除。
- Prompt 支持通过按钮或输入 `@` 插入 `@音频1`～`@音频3`，并在提交前检查空槽位和错误编号。
- 图片模式支持 PNG、JPEG、WebP；前后端都限制 10MB，并阻止图片和声音混用。
- 基础参数包含语速和格式；高级参数按一行排列采样率、音量、音调、字幕时间戳、显式水印和来源元数据。
- 生成描述下方与其他模型共用同一套字数、文本清洗、数字规范、分句预览和生成按钮工具栏。
- 生成仍进入原有任务、历史、下载和复用流程，没有新增独立页面。

## 架构结果

- 新增 Engine UI Registry、Generic Profile 和 Seed 专属 Profile 的模块化基础；当前生成页仍通过明确的 Seed 分支挂载专属面板，尚未宣称所有模型已完全配置驱动。
- Seed 的状态、请求转换、校验、预设和组件放在独立目录；Seed 专属参数与其他模型状态相互隔离。
- 后端新增引擎 Adapter Registry、Seed 专属 schema、素材解析、校验和 client。
- 云端请求发出前先保存请求 ID；状态不确定时不自动重放，取消或重试需要明确确认，避免重复扣费。
- 下载结果只接受可信 HTTPS 域名，拒绝 localhost、私网地址和不可信重定向；限制 JSON 和音频体积并校验音频文件头。
- 图片和音频素材使用受管理 ID，任务和历史只保存摘要，不保存 Base64、Key 或任意本机绝对路径。
