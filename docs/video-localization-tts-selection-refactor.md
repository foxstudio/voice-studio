# 视频本土化双轨配音选择重构计划

## 目标

把“ASR 参考声音选择”和“本土化合成台词选择”拆成两个独立坐标，并以一个版本化、不可变的参数包贯穿预览、直接生成、语音合成页调整、任务历史和时间线回填。

## 固定规则

- ASR 轨选择决定参考人声音频的出入点和 `ref_text`。
- 本土化轨选择决定合成台词和生成结果的时间线落点。
- 两组选择允许处于不同时间。
- 默认使用项目已有的最终 ASR；只有语音合成页调整自由参考选区后才重新识别。
- 双轨绑定使用稳定 ID，不使用中英文语义或运行时重叠作为权威关系。
- 普通时间线编辑选择与配音参数选择必须分离，避免关联高亮参与删除、移动或合并。

## 目标架构

1. `subtitle_linkage`：绑定归一化、双向索引、孤儿/过期/漂移状态。
2. `tts_selection`：解析双轨选择并生成冻结的 source/target 快照。
3. `tts_reference`：参考范围、说话人、裁切和参考文本。
4. `tts_parameter_pack`：版本化的唯一前后端合同。
5. `tts_workflow`：任务生命周期。
6. `tts_placement`：基于提交快照回填结果，不从当前字幕重新推导。
7. 前端 `tts-selection-session`：锚点轨、显式 ASR 选择、显式本土化选择、自动关联和人工排除。

## 迭代顺序

1. 建立新合同、绑定解析器和 golden tests，不改变现有 UI。
2. 解耦 source reference window 与 target placement window，并冻结 workflow 快照。
3. 上线双轨选择状态机、联动高亮、Ctrl/Cmd 加减选和生成前摘要。
4. 将删除、拆分、合并迁入事务性字幕变更服务，维护或标记绑定。
5. 统一单条/多条/批量生成合同和结果回填。
6. 完成旧项目兼容审计后，删除重复解析、核心 `group_*` 推导和多套前端选择同步。

## 删除门禁

- 新旧请求 golden comparison 通过。
- 当前项目及旧项目样本均可生成 v2 binding。
- 没有进行中的旧 workflow。
- 兼容路径调用为零。
- 单元、集成、前端检查、生产构建和浏览器端到端场景全部通过。

## 浏览器端到端场景

- ASR 单选、本土化单选和默认联动。
- 任一轨道作为锚点。
- Ctrl/Cmd 加选、减选；被动轨单独排除；恢复自动关联。
- ASR 多选 + 不同时间的本土化多选。
- 非连续来源、跨说话人、空目标和悬空绑定的阻断提示。
- 发送语音合成页后修改参考选区、重新识别并提交。
- 本土化页直接生成、任务状态、取消、删除、历史复用和时间线回填。
- 移动、拆分、合并、删除后绑定状态与生成参数仍正确。
