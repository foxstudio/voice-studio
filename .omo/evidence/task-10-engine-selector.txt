Task 10: 前端引擎选择器
========================
Wave 3 T10 — 在生成页添加动态引擎选择下拉框

修改文件清单
------------
1. frontend/src/routes/generate/+page.svelte (核心修改)
2. .omo/plans/002-three-engines-complete.md (checkbox 更新)

功能描述
--------
- 引擎下拉框：从 listEngines() API 动态加载，默认 indextts (v2)
- Capability-driven 参数面板：
  - emotion_control → 显示情绪控制面板
  - voice_design → 显示 voice_mode 下拉框 (auto/clone/design)
- v2 专属参数仅在 indextts 引擎时显示（避免 OmniVoice 误显）
- engineVersion 由 engineId 派生（indextts-v1 → v1，其余 → v2）
- 情绪控制面板：enable_emotion (checkbox) + emotion_strength (slider)
- OmniVoice 专属：voice_mode 选择（auto/clone/design）

验证方式
--------
- lsp_diagnostics: 无新增错误，仅有既有 Biome warnings
- listEngines() API 返回 EngineDetail[]，前端通过 $effect 加载
- 默认 engineId = 'indextts' 保持现有 v2 推理流程不变
